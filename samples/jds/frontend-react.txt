Senior Frontend Engineer — React

About Us

We build B2B SaaS dashboards used by operations teams at Fortune 500 companies. We are seeking a Senior Frontend Engineer who is exceptional with React, cares deeply about UI quality, and can drive a design system from scratch.

- 5+ years of professional frontend engineering experience
- Expert-level React and TypeScript — you live and breathe component composition and hooks
- Next.js for server-side rendering, static generation, and API routes
- State management experience: Zustand, Redux Toolkit, or React Query
- TailwindCSS and experience building design systems or component libraries
- Accessibility (WCAG 2.1 AA) best practices
- Unit and integration testing with Jest and React Testing Library
- Experience with Storybook for component documentation
- Strong understanding of Core Web Vitals, Lighthouse, and performance optimization
- Familiarity with CI/CD pipelines and code review practices
